# Privacy

IOSoccer Troubleshooter does not include advertising, analytics, accounts, or maintainer-operated telemetry.

The application reads local Steam configuration, IOSoccer files, Windows registry values scoped to IOSoccer, display settings, and user-selected configuration paths. Backups and configuration changes remain on the user's computer.

The application does not upload this information. Actions that launch Steam use a local Steam URI; any resulting Steam network activity is governed by Valve's privacy policy. The maintainer receives information only when a user deliberately includes it in a report.

Users can remove generated backups and local configuration files at any time.
