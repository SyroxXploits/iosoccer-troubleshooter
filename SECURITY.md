# Security Policy

Security fixes are provided for the latest release and the current default branch.

Do not disclose exploitable vulnerabilities in a public issue. Use GitHub private vulnerability reporting when available, or contact the maintainer through the contact method on the [SyroxXploits profile](https://github.com/SyroxXploits).

Include the affected version, impact, reproduction steps, and proposed mitigation. Do not test registry deletion, configuration replacement, game-folder deletion, or launch operations on systems you do not own or have permission to use.
